# PPE Detection for Workplace Safety

An AI-based computer vision project for detecting personal protective equipment (PPE) in workplace environments.

## Project Overview

This project focuses on detecting workplace safety equipment such as helmets and safety vests using deep learning and object detection techniques. The system can be used to support safety monitoring in construction sites, factories, and industrial environments.

## Main Features

- Detect safety helmet and no-helmet cases
- Detect safety vest and no-vest cases
- Support real-time or image/video-based detection workflow
- Provide detection results for workplace safety monitoring
- Can be integrated with notification systems such as Telegram

## Technologies Used

- Python
- OpenCV
- Deep Learning
- Computer Vision
- YOLO
- Ultralytics
- Google Colab / Kaggle
- Telegram Bot integration
